# Инфраструктурный проект

Учебный репозиторий с каркасом инфраструктуры: Terraform для создания ресурсов и Ansible для конфигурации сервисов (веб, мониторинг, логи). Содержимое оформлено по разделам и структуре, удобной для пошаговой реализации.

## Содержимое
- Terraform: каталог `terraform/` — провайдер, сеть, ВМ, группы и L7-балансировщик.
- Ansible: каталог `ansible/` — инвентори, роли `nginx`, `zabbix`, `filebeat`, плейбук `site.yml`.
- Архив «как было»: `docs/legacy/`.

## Быстрый старт
- Требования: установленный Terraform и Ansible, доступ к облаку, SSH-ключи.
- Шаги:
  - Заполнить провайдер и переменные в `terraform/`.
  - Выполнить `terraform init && terraform apply`.
  - Заполнить `ansible/inventories/prod/hosts.ini` и выполнить `ansible-playbook playbooks/site.yml`.

## Инфраструктура
- Базовый провайдер и настройки лежат в `terraform/main.tf`.
- Далее планируется описать сети, ВМ и балансировку в отдельных файлах.

## Сеть
- VPC, подсети и необходимые правила — `terraform/net.tf`.
- Связка ресурсов безопасностью и группами описывается отдельно.

## Сайт (Ansible)
- Плейбук: `ansible/playbooks/site.yml`.
- Роли: `ansible/roles/nginx`, `ansible/roles/zabbix`, `ansible/roles/filebeat`.
- Инвентори: `ansible/inventories/prod/hosts.ini`. При необходимости используйте bastion/jumphost.

## Мониторинг
- Развёртывание Zabbix-сервера и агентов планируется ролью `zabbix`.
- Базовые проверки веб-интерфейса и статуса сервисов — отдельными тасками.

## Логи
- Стек логирования (Elasticsearch/Kibana) и отправка логов средствами Filebeat.
- Проверки индексов и доступности — отдельные таски.
